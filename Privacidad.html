Política de Privacidad

Última actualización: 9 de agosto de 2026.

1. Información general

Smirplay2 respeta la privacidad de los usuarios que visitan este sitio web.

2. Información utilizada

El sitio puede utilizar servicios de plataformas externas para mostrar contenido deportivo publicado en redes sociales.

Cuando un usuario autoriza una integración con TikTok u otra plataforma, únicamente se utilizará la información necesaria para mostrar contenido autorizado dentro del sitio.

3. TikTok

Smirplay2 puede utilizar la API de TikTok para consultar y mostrar publicaciones públicas del perfil autorizado, incluyendo videos y publicaciones relacionadas con jugadores destacados.

4. Servicios externos

Este sitio puede contener enlaces o contenido integrado de TikTok, Instagram, YouTube, Facebook y Kick. Estas plataformas cuentan con sus propias políticas de privacidad.

5. Contacto

Para cualquier duda relacionada con esta política de privacidad, puedes contactar a Smirplay2 mediante los medios disponibles en la sección de contacto del sitio.
